📋 使用说明
1. 配置模型：点击右上角 ⚙️ 按钮，填写火山引擎 API Key、Base URL 和模型名称，点击测试连接验证配置。
2. 填写信息：输入工程名称、核心需求、当前轮次和阶段描述。
3. 上传截图：拖拽或点击上传运行结果截图（支持多张）。
4. 提交验收：当需求、截图和配置都完整时，「提交验收」按钮将自动启用。

⚠️ 注意事项：
- 提交验收前请确保后端服务已启动（运行 python server.py）
- API Key、Base URL 和模型名称必须完整配置
- 至少上传一张截图才能提交验收
